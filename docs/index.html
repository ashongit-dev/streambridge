From clone to control room

Bring your feeds.
We’ll bridge the gap.

Run Streambridge on a computer or server with Docker Compose and Python 3.9+. Connect your publishing devices and manage the broadcast from your browser.

QUICK STARTTERMINAL
git clone https://github.com/ashongit-dev/streambridge.git
cd streambridge
cp .env.example .env

# Set your passwords and server address in .env
python3 configure.py
docker compose up -d --build

Set two strong, different passwords before starting. See the full setup guide for prerequisites, configuration, and access to the repository.

Read the setup guide ↗

  1. Start your relay

    Configure your server address and passwords, then start the Docker services. Open the dashboard at localhost:8080, or reach a remote server through an SSH tunnel or HTTPS proxy.

  2. Connect desk and IRL

    Copy the server and publishing key for each feed into OBS or your IRL app. Send H.264 video with AAC audio. Both incoming feeds have their own browser preview.

  3. Choose your destination

    Enter your Twitch or other RTMP/RTMPS server URL and stream key in the dashboard. Start the outgoing broadcast once.

  4. Take the moment with you

    Switch sources from your browser. Keep automatic backup enabled and your relay server online. Closing the dashboard won’t stop your broadcast.

A few things to know

Your broadcast.
Your infrastructure.

Does GitHub Pages run the streaming app?

This is the product website. The RTMP relay, encoder, and live control dashboard run on your own Docker host. GitHub Pages serves this static website.

What happens when both feeds go offline?

Streambridge selects the fallback graphic with silent audio while keeping the outgoing encoder running. It can return to your preferred feed after recovery. The relay server and its connection to the destination must remain online.

Can I control it from my phone?

Yes. The dashboard works in a browser. For a remote server, use a trusted VPN or an HTTPS reverse proxy. The dashboard binds to localhost by default; the setup guide explains remote access.

Are previews instant?

No. Incoming previews use HLS and run a few seconds behind. Switching happens at the relay, so the preview is not a frame-accurate view of the outgoing cut.

Can I use my own destination and fallback?

Yes. Enter an RTMP or RTMPS server and stream key in the web UI. Upload a PNG or JPEG fallback graphic up to 8 MB, fitted to the 16:9 canvas. Changing destinations requires stopping the current output first.

Does this protect against a server outage?

The fallback protects against input-feed loss. A relay-server outage, outgoing network failure, or destination-platform outage can still interrupt or end a broadcast.
